# Support

Use GitHub Issues for reproducible defects and feature requests. Include the
server and chart version, Jenkins version, deployment method, CPU architecture,
whether Minibridge is enabled, sanitized server/Minibridge logs, and reproduction
steps.

Do not post Jenkins API tokens, authentication headers, private CA material,
internal URLs, or confidential build logs. Report suspected vulnerabilities
privately through GitHub Security Advisories as described in `SECURITY.md`.
